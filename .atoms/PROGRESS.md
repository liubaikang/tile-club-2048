# Requirements & Progress

## Requirements Overview
2048 网页版游戏，可在线游玩并部署到页面；需要账户注册与账户管理；游客默认获得按设备信息生成的游客身份。

## User Stories
- 作为访客，我打开页面即可直接开始 2048，成绩自动归入我设备的游客身份。
- 作为访客，我可以修改昵称、查看自己的对局历史、随时登录或注册升级为正式账户。
- 作为登录用户，我可以用方向键/滑动游玩，结束后成绩自动上榜，可在账户页查看统计与历史。
